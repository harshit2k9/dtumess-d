# DTU Hostel Mess Schedule Portal

A clean, responsive, and light/dark theme-compatible hostel mess schedule manager built for Delhi Technological University (DTU) students. Available both as a standalone single-file web application and as a cross-platform Flutter mobile application.

---

## Features

- **Time-Aware Greeting:** Dynamically displays "Good Morning", "Good Afternoon", or "Good Evening" based on the user's local device time.
- **Dietary Filters:** Instantly toggle between **ALL**, **VEG ONLY**, and **NON-VEG ONLY** items.
- **Search Functionality:** Real-time search across meal items (e.g., search for "Paneer", "Eggs", "Biriyani").
- **Day Selector:** Quickly view menus for any day of the week, with an automatic default selection for today.
- **Meal Skipping:** Track skipped meals with visual strikethrough feedback.
- **User Profile Management:** Store and edit student name and room/hostel details locally.
- **Dark Mode Support:** Adapts to system light/dark theme settings.
